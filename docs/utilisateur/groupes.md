# Les groupes : mode d'emploi

Ce document explique comment consulter la page **Groupes** du site : qui peut y accéder, ce qu'on y voit, comment s'en servir sur ordinateur, et ce qui change sur téléphone.

---

## 1. À quoi sert la page Groupes

La page Groupes affiche, **pour la saison en cours**, la liste des adhérents de chaque groupe du club (formations, sections, activités).

D'un coup d'œil, vous savez :

- qui fait partie de votre groupe, avec sa photo ;
- si son **certificat médical (CACI)** est valide, et jusqu'à quand ;
- si sa **licence FFESSM** est valide, et jusqu'à quand ;
- quels **brevets** il possède (en mode Détail, voir §4.2) ;
- comment le joindre (téléphone, e-mail, personne à prévenir), en ouvrant sa fiche.

La page est en **lecture seule** : on ne modifie rien depuis cette page. Un adhérent rejoint un groupe en le choisissant dans son **formulaire d'adhésion**. Pour corriger une composition de groupe, adressez-vous au bureau.

---

## 2. Qui peut y accéder

| Profil | Accès |
| --- | --- |
| **Moniteurs** | Oui |
| **Responsables de groupe** | Oui |
| **Membres du bureau** | Oui |
| Autres adhérents | Non |
| Public (Non conecté) | Non |

Un adhérent sans l'un de ces rôles qui ouvre l'adresse de la page est renvoyé vers l'accueil du site avec le message « Vous n'êtes pas autorisé à accéder à cette page ».

> **Bon à savoir** : les informations affichées (téléphone, e-mail, personne à prévenir, certificat médical) sont **personnelles**. Elles servent à l'encadrement des activités : ne les diffusez pas en dehors du club.

---

## 3. Ce que la page affiche

### 3.1 Les groupes

- Un onglet par groupe du club, dans l'ordre défini par le bureau, avec une pastille indiquant le **nombre d'adhérents**.
- Un premier onglet **« Tous les groupes »** réunit tous les adhérents inscrits dans au moins un groupe. Un adhérent présent dans plusieurs groupes n'y apparaît **qu'une fois**.
- L'interrupteur **« Masquer les groupes vides »** (activé par défaut) cache les groupes qui n'ont encore aucun adhérent cette saison. Désactivez-le pour voir tous les groupes.

Si aucune saison n'est ouverte, la page affiche « Aucune saison ouverte. » et ne liste personne.

### 3.2 Les badges CACI et Licence

Chaque adhérent porte deux badges, qui indiquent la **date de fin de validité** du document.

| Badge | Icône | Couleur | Signification |
| --- | --- | --- | --- |
| **CACI** | 🩺 dossier médical | 🟢 vert | Valide |
| | | 🟠 orange | Expiré, ou expire dans moins de 3 mois |
| | | 🔴 rouge | Manquant (pas de fichier ou pas de date) |
| **Licence** | 🪪 carte | 🔵 bleu pâle | Valide (y compris si elle expire bientôt) |
| | | 🔴 rouge pâle | Expirée ou manquante |

Survolez un badge avec la souris pour afficher son statut en toutes lettres.

**Cliquez sur le badge CACI** pour afficher le certificat médical en grand. Fermez la fenêtre avec la **croix** en haut à droite, la touche **Échap** ou un clic en dehors de l'image.

> **À faire** : avant une activité, vérifiez qu'aucun participant n'a un badge CACI orange ou rouge. Un CACI expiré doit être renouvelé avant de plonger.

### 3.3 La fiche de l'adhérent

**Cliquez sur le nom** d'un adhérent pour ouvrir sa fiche : photo, téléphone, e-mail et **personne à prévenir** en cas d'urgence. Les membres du bureau y voient aussi l'adresse postale.

## 4. Sur ordinateur (et tablette à l'horizontale)

### 4.1 Naviguer entre les groupes

Les groupes sont présentés sous forme d'**onglets** en haut de la liste. Cliquez sur un onglet pour afficher le groupe correspondant.

### 4.2 Choisir le mode d'affichage

Deux boutons en haut à gauche permettent de changer de présentation. Le choix s'applique à tous les onglets.

| Mode | Présentation | Idéal pour |
| --- | --- | --- |
| **Vignette** (par défaut) | Une carte par adhérent : nom, grande photo, badges CACI et Licence | Reconnaître les adhérents, faire l'appel au bord du bassin |
| **Détail** | Un tableau : photo, nom, brevets, licence, CACI | Rechercher, trier, contrôler les brevets, imprimer |

**Le mode Détail offre en plus :**

- une zone **« Rechercher… »** qui filtre instantanément les lignes (sur le nom, un code de brevet, une date…) ;
- le **tri** en cliquant sur l'en-tête d'une colonne ;
- le choix du **nombre de lignes par page** ;
- la colonne **Brevets** : les principaux brevets de l'adhérent sous forme de codes, en deux couleurs pour distinguer brevets de **pratiquant** et brevets d'**encadrant** (survolez un code pour son libellé complet). Le lien **« Voir tout »** ouvre la liste complète de ses brevets ;
- un clic sur la **photo** l'affiche en grand.

### 4.3 Exporter en PDF

Le bouton **« Exporter en PDF »**, en haut à droite de chaque groupe, ouvre la fenêtre d'impression du navigateur. Choisissez **« Enregistrer au format PDF »** comme imprimante pour obtenir un fichier, ou une imprimante pour une feuille papier.

> **À faire** : passez en mode **Détail** avant d'exporter. L'export imprime alors uniquement le tableau du groupe affiché, avec la recherche et le tri en cours. En mode Vignette, c'est la page entière qui est imprimée.

## 5. Sur téléphone

Quand l'écran fait **moins de 768 pixels de large** (téléphone, ou petite tablette tenue à la verticale), la page s'adapte pour rester lisible d'une main.

### 5.1 Ce qui change

| Élément | Sur ordinateur | Sur téléphone |
| --- | --- | --- |
| Choix du groupe | Onglets | **Liste déroulante « Groupe affiché »** en haut de page, avec le nombre d'adhérents de chaque groupe |
| Mode d'affichage | Vignette ou Détail, au choix | **Vignette uniquement** (le tableau n'est pas lisible sur un petit écran) |
| Vignettes par ligne | 3 à 4 | **2** |
| Nom sur la vignette | Civilité + nom et prénom | Nom et prénom seuls, sur **deux lignes** au maximum |
| Colonne Brevets | Visible en mode Détail | **Non affichée** |
| Recherche, tri | Disponibles en mode Détail | **Non disponibles** |
| Export PDF | Disponible | **Non disponible** |
| Fil d'Ariane du site | Affiché | Masqué, pour gagner de la place |

### 5.2 Ce qui reste identique

- L'interrupteur **« Masquer les groupes vides »** : les groupes vides disparaissent aussi de la liste déroulante.
- Le groupe **« Tous les groupes »**, en premier choix de la liste.
- Les badges **CACI** et **Licence**, avec les mêmes couleurs.
- Un appui sur le **badge CACI** affiche le certificat en grand ; la **croix** en haut à droite referme la fenêtre.
- Un appui sur le **nom** ouvre la fiche de l'adhérent : depuis un téléphone, le numéro et l'e-mail sont directement utilisables pour appeler ou écrire.

### 5.3 Tourner le téléphone

Si vous passez le téléphone (ou la tablette) à l'horizontale et que l'écran dépasse 768 pixels, la présentation ordinateur s'affiche, avec ses onglets et le mode Détail. En revenant à la verticale, la page repasse automatiquement en vignettes.

> **À faire** : pour rechercher un adhérent, consulter ses brevets ou préparer une feuille de présence, utilisez un **ordinateur**. Au bord du bassin, le **téléphone** suffit pour vérifier les visages, les CACI et les numéros d'urgence.

## 6. Questions fréquentes

**Un adhérent de mon groupe n'apparaît pas.**
La page ne montre que les adhérents de la **saison en cours** qui ont choisi ce groupe lors de leur adhésion. Si l'adhésion n'a pas été faite, ou si le groupe n'a pas été coché, l'adhérent n'apparaît pas. Signalez-le au bureau.

**Un groupe que je connais n'apparaît pas.**
Vérifiez l'interrupteur « Masquer les groupes vides » : le groupe n'a peut-être encore aucun adhérent. S'il n'apparaît toujours pas, il n'est pas publié : voyez avec le bureau.

**Le badge CACI est rouge alors que l'adhérent affirme l'avoir envoyé.**
Le badge est rouge si le fichier **ou** la date de fin de validité manque. L'adhérent peut compléter son CACI depuis sa page **Profil** ; le secrétariat peut aussi corriger la date.

**Je ne trouve pas le bouton Détail ni l'export PDF.**
Vous êtes sur un écran étroit (téléphone). Passez sur un ordinateur, ou tournez votre tablette à l'horizontale.
